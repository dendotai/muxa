# Installation

Install muxa globally, or in a project.

## Global

<Tabs items={["Bun", "npm", "pnpm", "Yarn"]}>
  <Tab value="Bun">

    ```bash
    bun add -g @den-ai/muxa
    ```

  </Tab>
  <Tab value="npm">

    ```bash
    npm install -g @den-ai/muxa
    ```

  </Tab>
  <Tab value="pnpm">

    ```bash
    pnpm add -g @den-ai/muxa
    ```

  </Tab>
  <Tab value="Yarn">

    ```bash
    # Yarn 1; Yarn 2 and later has no global install
    yarn global add @den-ai/muxa
    ```

  </Tab>
</Tabs>

## In a Project

As a dev dependency, everyone on the team runs the same version, and `package.json` scripts can call `muxa`:

<Tabs items={["Bun", "npm", "pnpm", "Yarn"]}>
  <Tab value="Bun">

    ```bash
    bun add -d @den-ai/muxa
    ```

  </Tab>
  <Tab value="npm">

    ```bash
    npm install -D @den-ai/muxa
    ```

  </Tab>
  <Tab value="pnpm">

    ```bash
    pnpm add -D @den-ai/muxa
    ```

  </Tab>
  <Tab value="Yarn">

    ```bash
    yarn add -D @den-ai/muxa
    ```

  </Tab>
</Tabs>

## Without Installing

```bash
npx @den-ai/muxa -s frontend dev -s backend dev
bunx @den-ai/muxa -s frontend dev -s backend dev
```

## Requirements

- **Node.js** >= 22. Without Node.js, muxa runs through Bun: from a `package.json` script with `bun run`, or with `bunx`.
- **dekit** (automatically installed as dependency), for macOS and Linux on x64 and arm64

## Verify Installation

After installation, verify that muxa is available:

```bash
muxa --version
```

You should see the version number displayed.

## Platform Support

- macOS
- Linux
- Windows through WSL (Windows Subsystem for Linux), because muxa runs commands with `sh`

## Troubleshooting

### Command not found

If you get a "command not found" error after installation, you may need to add the global bin directory to your `PATH` in your shell profile (`~/.bashrc`, `~/.zshrc`, etc.):

<Tabs items={["Bun", "npm", "pnpm", "Yarn"]}>
  <Tab value="Bun">

    ```bash
    # Find bun global bin directory
    bun pm bin -g

    # Add to your shell profile
    export PATH="$PATH:$(bun pm bin -g)"
    ```

  </Tab>
  <Tab value="npm">

    ```bash
    # Find npm global bin directory
    echo "$(npm prefix -g)/bin"

    # Add to your shell profile
    export PATH="$PATH:$(npm prefix -g)/bin"
    ```

  </Tab>
  <Tab value="pnpm">

    ```bash
    # Find pnpm global bin directory
    pnpm bin -g

    # Add to your shell profile
    export PATH="$PATH:$(pnpm bin -g)"
    ```

  </Tab>
  <Tab value="Yarn">

    ```bash
    # Find yarn global bin directory
    yarn global bin

    # Add to your shell profile
    export PATH="$PATH:$(yarn global bin)"
    ```

  </Tab>
</Tabs>

### Permission errors

If you encounter permission errors during global installation:

1. **Recommended**: Configure npm to use a different directory for global packages
2. **Alternative**: Use a Node version manager like nvm, fnm, or volta
3. **Not recommended**: Use sudo (can cause permission issues later)
